Lumière Web Studio

Web制作会社「Lumière Web Studio」を想定して制作したコーポレートサイトです。
シンプルで落ち着いたデザインを意識し、サービス内容や制作実績、FAQ、お問い合わせへの導線を分かりやすくまとめました。

制作目的

HTML、CSS、JavaScriptを使用したWebサイト制作の実践的な学習を目的として制作しました。
また、レスポンシブ対応やJavaScriptによるインタラクションの実装、Git/GitHubを使用したバージョン管理からWebサイトの公開までを一通り経験することを目的としています。

工夫したポイント

・レスポンシブ対応
PCだけでなくスマートフォンでも閲覧しやすいように、画面幅に応じてレイアウトが変化するようCSSを調整しました。
・JavaScriptによるインタラクション
ユーザーが操作したときに変化が分かりやすくなるよう、ハンバーガーメニュー、FAQの開閉、スクロール時のアニメーションを実装しました。
・シンプルで見やすいデザイン
Web制作会社のコーポレートサイトを想定し、余白を広めに取り、落ち着いた配色を使用しました。
